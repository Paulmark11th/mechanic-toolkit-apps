Code meanings follow the generic OBD-II standard (SAE J2012) used on most 1996+ US vehicles and 2001+/2004+ European petrol/diesel vehicles. Manufacturer-specific codes (P1xxx, many B/C/U codes) can mean different things on different brands, so confirm those in a factory service manual. Causes are listed from most to least common, but a code only points you to a system. Test before you replace parts. Never work on airbag (SRS) or high-voltage hybrid/EV systems without proper training.
